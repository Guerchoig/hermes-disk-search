## Исправления (все — по живому инциденту установки на чистой машине)

* **`llm_host.exe` из CI-сборки не стартовал на других машинах** — «конфиг
  D:\a\hermes-disk-search\...\config.yaml: не читается (os error 2)». Причина: корень
  проекта резолвился на этапе компиляции (`CARGO_MANIFEST_DIR` машины сборки), туда же
  смотрели pid/лог. Теперь корень определяется по расположению exe (`bin\x.exe` →
  корень установки, `HDS_ROOT` — переопределение), как уже сделано в `hds-core`
  для `project_root()`.
* **Фасад `:8010` отвечает на CORS-preflight (OPTIONS)** — раньше 404. Вебвью Cline
  (Electron) при запросе каталога моделей с заголовком `Authorization` требует
  предварительный OPTIONS; без него запрос из браузерного контекста не проходит.
* **«Синхронизировать настройки Cline» больше не требует ручного ввода модели**:
  cline-sync сам создаёт отсутствующие записи `chat` / `chat-think` в `models.json`
  (с окнами контекста слотов и capabilities) и заменяет фантомный
  `defaultModelId: "gpt-4o"` (статическая заглушка каталога Cline) на `chat`.
* **Установщик проверяет версию Cline Desktop**: сборки, где каталога моделей ещё нет
  (< 0.0.43, по живым проверкам 05.10.2026), теперь дают явное предупреждение
  об обновлении Cline.
* `publish_clip_models.ps1` больше не роняет себя на stderr-выводе `gh` при
  `$ErrorActionPreference = "Stop"` (PowerShell 5.1) — публикация CLIP-моделей
  (тег `clip-onnx-v1`) проходит до конца, включая создание релиза.

## Требования к обновлению

* Обновление с 0.15.0 — штатное: распаковать архив поверх, запустить
  `setup.cmd`/`setup.ps1` (или `installers\update.ps1`); переиндексация не требуется.
* Если Cline Desktop на машине **старее 0.0.43** — обновите Cline
  (https://github.com/cline/cline/releases/latest): в старых сборках шаг
  `models.json` синхронизации останется «не найден».
* После синхронизации настроек Cline перезапустите Cline (Desktop/CLI).

## Примечание

* Кнопка «обновить список моделей» у провайдера «OpenAI Compatible» в Cline не
  подтягивает модели с `baseUrl` — у этого провайдера каталог статический, модели
  вводятся вручную (или создаются нашим `cline-sync`, см. `sync_models` в
  `crates/hds-core/src/cline.rs`).
