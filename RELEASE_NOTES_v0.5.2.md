# hermes-disk-search v0.5.2

## Изменено

- **Упрощён состав релиза**: отдельный ассет `HermesDiskSearchIndex.app.zip` убран —
  mac-приложение «HDS Индексация» и так находится внутри полного mac-архива
  (`git archive`), отдельный ассет дублировал его.
- Пользу ad-hoc подписи приложение не потеряло: теперь инсталлятор macOS
  подписывает копию приложения **на целевой машине** (`codesign --force --deep
  --sign -` после копирования в ~/Applications; codesign входит в macOS,
  ad-hoc бесплатна) — кодовые подписи нельзя закоммитить в архив, поэтому это
  единственное корректное место для них.
- README и releasing.md обновлены: релиз = два полных архива (Windows/macOS).

## Требования к обновлению

- Обычное обновление: распаковать архив релиза и запустить `setup.cmd`
  (Windows) / `bash installers/install_macos.command` (macOS).
  Переиндексация не требуется.
