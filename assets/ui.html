    Пример: D:\Backup\Downloads\opencv — папка целиком не индексируется (префикс пути).

    LLM-серверы (llama.cpp)

    …
    Модель bge-m3 нужна для поиска «по смыслу»; чат-модель (qwen3.5-9b) — для ответов ask_my_files. Серверы поднимаются автоматически при старте UI/MCP (llm_server.autostart) и переживают перезапуск. Файлы моделей лежат в папке models/ проекта. Ручное управление: python -m hds.llama_server status|start|stop [chat|embedding|rerank].

    Настройки (config.yaml)

    Пути индексирования — секция index.roots; изменения применяются к новым запускам: после сохранения перезапустите watcher/индексацию кнопками выше.

    Расположение базы индексации

    Перенос атомарный: индексация приостанавливается, копия проверяется, db_path переключается, старая база остаётся резервной копией (.moved-…), watcher и индексация возвращаются к прежнему состоянию.
