# Релиз v0.5.10

## Исправления

- **Из UI снова сохраняются все параметры и YAML-редактор настроек** (регрессия
  v0.5.8, проявлялась на свежих установках). CSRF-гард сервера принимает POST
  только с `Content-Type: application/json`, но в `assets/ui.html` пять
  вызовов отправляли тело без заголовка — браузер подставлял дефолтный
  `text/plain`, и сервер отвечал ошибкой «Content-Type должен быть
  application/json». Симптом: «Сохранить корни» работало, а «Сохранить
  настройки», параметры обработки («Транскрибировать», лимиты), «Сохранить
  исключения», галочка автозапуска watcher и «Переиндексировать» — падали.
  Теперь все POST-вызовы UI явно отправляют `application/json`.
- **Текст ошибки сервера виден в UI**: сообщения «Сохранить настройки»,
  параметров и исключений показывают реальный `error` сервера вместо
  безымянного «Ошибка».
- **Origin `http://localhost:<порт>` принят как свой** наравне с
  `http://127.0.0.1:<порт>` — интерфейс, открытый по localhost, больше не
  отклоняет все POST с 403.

## Тесты

- 140 регрессионных тестов зелёные (+1: localhost-Origin проходит CSRF-гард).

## Требования к обновлению

- Специальных действий не требуется: миграций БД нет, `config.yaml` совместим.
- После обновления обновите страницу UI с очисткой кэша (Ctrl+F5) — браузер
  должен забрать новый `assets/ui.html` (сервер отдаёт его с `no-store`,
  поэтому достаточно обычной перезагрузки).
