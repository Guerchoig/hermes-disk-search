# hermes-disk-search v0.5.5

## Исправления UI (устаревший UI-сервер на порту)

- **«not found» при сохранении корней устранено**: если на порту 8765 работал
  UI-сервер **предыдущей установки** (старый pythonw-процесс), он не знал новых
  эндпоинтов, и любые новые функции UI возвращали «not found». Теперь
  `run_ui.ps1` сверяет версию запущенного сервера с версией файлов проекта и
  **автоматически перезапускает устаревший сервер**.
- Веб-интерфейс показывает версию работающего сервера (бейдж «сервер: vX.Y.Z»).
- `/api/status` отдаёт `app_version` для диагностики.

## Требования к обновлению

- Установите поверх и запустите `setup.cmd` или ярлык «Hermes Disk Search» —
  устаревший сервер перезапустится автоматически. Если что-то держит порт,
  вручную: в Диспетчере задач завершите процессы pythonw.exe и запустите ярлык
  заново. Переиндексация не требуется.
