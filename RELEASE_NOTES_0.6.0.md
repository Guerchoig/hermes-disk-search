# hermes-disk-search v0.6.0

## Новое

- **Русская морфология в ключевом поиске (FTS)** — новая зависимость `pymorphy3`:
  в полнотекстовый индекс пишется лемматизированный текст, запрос лемматизируется
  тем же способом. Раньше «настройки» не находили «настройка», «скрипта» — «скрипты»;
  теперь разные словоформы находят друг друга. При отсутствии зависимости система
  работает без морфологии (предупреждение в `check` и веб-интерфейсе).
- Новая команда CLI **`python -m hds.cli reindex-fts`** — перестройка FTS-полнотекста
  из уже проиндексированных текстов (только CPU, без переэмбеддинга, OCR и
  транскрипции; ~30–90 мин на ~550 тыс. чанков).
- Инструмент оценки качества поиска **`tools/eval_retrieval.py`** (Фаза 0):
  генерация golden-set вопросов локальной чат-моделью по случайным чанкам и замер
  recall@5 / recall@10 / MRR / латентности по веткам «FTS», «вектор», «гибрид» —
  суммарно и по типам файлов. Результаты в `eval/` (не входят в репозиторий).

## Требуется после обновления

1. `setup.ps1` поставит `pymorphy3` при обновлении (или вручную:
   `.venv\Scripts\python.exe -m pip install pymorphy3 pymorphy3-dicts-ru`).
2. **Запустите `python -m hds.cli reindex-fts`** — иначе морфология применяется
   только к заново проиндексированным файлам (статус перестройки виден в `check`).

## Совместимость

- Схема БД не меняется (перестройка FTS — командой, векторы не затрагиваются).
- `config.yaml` совместим без изменений.
