# hermes-disk-search v0.3.0

Минорный релиз: поиск картинок по содержанию (CLIP), управление исключениями из UI,
интеграция с Hermes Desktop в один запуск, и серия исправлений стабильности.

## Новое

- **Поиск картинок по содержанию (CLIP)**: изображения кодируются CLIP ViT-B-32
  в отдельный векторный индекс (`images_vec`), запросы на любом языке (ru/en) — через
  multilingual text-энкодер. «Найди изображения живых цветов» находит фото по смыслу,
  а не только по имени файла. Вектор считается при индексации; для уже
  проиндексированных картинок — `python -m hds.cli clip-index` (дозаполнение фоном);
- **Имя папки в чанке картинки** — фото из осмысленных папок («Цветы», «Море 2015»)
  находятся по названию папки;
- **Исключаемые пути в UI**: настройка `index.exclude_paths` (префиксы путей — каталог
  целиком или отдельный файл), редактируется в «Параметрах обработки»; исключённые
  поддеревья отсекаются при обходе, watcher их игнорирует;
- **MS Project (.mpp)**: индексация задач с датами и ресурсами через mpxj
  (включён в requirements; Java подхватывается из `%LOCALAPPDATA%\jdk-21\`);
- **Автоподключение к Hermes Desktop**: `install_hermes.ps1` регистрирует MCP-сервер,
  устанавливает скилл «поиск файлов — через MCP» и выставляет
  `tools.tool_search.enabled: "off"` (все инструменты в промпте — критично для
  локальных моделей); вызывается из setup.ps1, работает и при установке Hermes позже.

## Исправления

- **Индексация более не падает на битых файлах**: повреждённые Office-документы
  (BadZipFile) и lock-файлы Office (`~$*.xlsx`) изолируются — статус `error`/пропуск
  вместо смерти watcher'а; watcher переживает сбой стартовой сверки;
- **Keep-alive в эмбеддерах** — убрано ~2 с оверхеда на каждый запрос к LM Studio
  (индексация ускорилась в десятки раз: файл 0.1-0.4 с вместо 2+ с);
- **Остановка watcher'а из UI работает**: поиск процессов переписан на psutil
  (PowerShell-вариант тихо возвращал пустой список), kill дерева процессов,
  статус не доверяет устаревшему watch.lock с переиспользованным PID;
- **UI больше не мигает**: ffprobe/ffmpeg/curl/tesseract запускаются без консольных
  окон; устранён дубль в JS страницы;
- **Строка скорости/ETA в UI не исчезает** при долгой обработке одного файла
  (периодический heartbeat + корректный расчёт ETA при пустом скользящем окне);
- heartbeat-дедлок (не-RLock) устранён — раньше индексация визуально
  «останавливалась» на каждом долгом файле;
- Tesseract OCR: русский язык через пользовательский tessdata (TESSDATA_PREFIX
  подхватывается автоматически), путь к tesseract.exe задаётся в config.yaml;
- статусная строка не падает в консолях без юникода (cp1251).

## Требования к обновлению

- Перезапустить watcher и Hermes Desktop; schema БД меняется автоматически
  (добавляется таблица `images_vec`), переиндексация `index --full` не требуется;
- Для поиска картинок по содержанию выполнить разово
  `python -m hds.cli clip-index` (первые модели CLIP скачаются автоматически, ~1.7 ГБ);
- Python-зависимости: добавились `sentence-transformers`, `mpxj`, `jpype1`, `psutil`
  (`pip install -r requirements.txt`).
