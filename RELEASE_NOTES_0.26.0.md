# hermes-disk-search 0.26.0 — зеркало папки проекта (фаза A4)

**Дата:** 20.11.2026 · **База:** 0.25.0 · **Ветка:** `agent-privacy-zone`

**Фаза A4** связывает папку проекта пользователя с анонимной зоной в обе стороны и умеет
работать в фоне. Пользователь сохраняет документ — через несколько секунд его обезличенная
копия уже в `<agent.root>\P<NNNN>\workspace`; агент правит копию — рядом с документом
появляется вариант на утверждение. Оригиналы без решения пользователя не меняются.

## Что нового

### Зеркало (TR-7.1…TR-7.9)

1. **`hds agent sync --project <P> [--once | --interval SEC]`**: один проход (без флагов и с
   `--once`) или демон по таймеру (`--interval`, по умолчанию `agent.sync.interval_sec` = 5 с).
   Повторный проход по неизменённой папке — 0 изменений.
2. **Прямой путь**: структура папок повторяется, имена обезличиваются метками без падежа
   (`Протоколы\Встреча с [PERSON_3].docx`), docx/xlsx/txt/md/xml — образ, pdf/pptx/mpp —
   текстовый образ `*.pdf.md`; недописанный файл зеркало ждёт (`wait_stable`), неподдерживаемые
   и слишком большие файлы получают статус в реестре, а не ошибку.
3. **Обратный путь**: правка образа → деанонимизированный вариант в `.hds-agent\pending` со
   снимком основания; новый файл агента появляется в папке проекта сразу, без папки «Входящие»;
   защита от петель по маркеру `hds-agent/<P>/<id>`.
4. **Решения**: `hds agent result accept|reject|conflict` — копия оригинала в `backup` и замена,
   отклонение с сообщением агенту (`messages.jsonl`), три исхода конфликта, честное «файл занят».
5. **Валидатор**: к каждому варианту — `pending\<rel>.report.json` с четырьмя проверками (метки
   вне проекта, падеж, непомещённые `[IMAGE_n]`, потеря текста > 40 %); пометка «проверить»
   ничего не блокирует.
6. **Демон**: остановка по `hds stop` (`index.stop`) и Ctrl+C, lock `sync.lock` в
   `<P>\agent-state` (второй демон не стартует), журнал `agent-state\sync.log` — строки
   `start`/`pass`/`problem`/`error`/`stop` только с путями, метками, статусами и числами;
   ошибка прохода демон не убивает.

### Документация

7. `README.md` §20: подразделы «Зеркало папки проекта», «Вариант, отчёт и решение», «Режим
