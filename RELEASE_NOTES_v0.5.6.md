# hermes-disk-search v0.5.6

## Исправления (несовпадение имени модели эмбеддингов)

Симптом: индексация идёт, GPU (Vulkan) занят — эмбеддинги реально считаются, но UI
пишет «модель не загружена», а после манипуляций с моделями в LM Studio сервер
отдаёт модель под **другим идентификатором**, не совпадающим с `embedding.model`
в config.yaml (было и две копии модели от двух источников).

- Сопоставление модели теперь по **базовому имени** (bge-m3), а не по точному id:
  карточка «Модель эмбеддингов» показывает 🟡 с фактическим именем сервера
  и кнопку **«⤵ Применить имя модели»** — она обновляет `embedding.model`
  в config.yaml под фактический идентификатор LM Studio.
- Диагностика («Проверить») при несовпадении имён показывает ⚠ с подсказкой
  вместо ложной «недоступности».
- **Кнопка «🔄 Проверить» снова работает**: раньше её нажатие проглатывалось
  авто-проверкой (интервал 2 с).

## Требования к обновлению

- Установите поверх и перезапустите UI (ярлык сам перезапустит устаревший
  сервер — см. v0.5.5), в браузере Ctrl+F5. В карточке «Модель эмбеддингов»
  нажмите «⤵ Применить имя модели», затем перезапустите watcher/индексацию.
  Переиндексация не требуется.
