# hermes-disk-search v0.5.3

## Исправления и улучшения установки (whisper.cpp / Vulkan)

- **`vulkan-setup` устанавливает бэкенд полностью автоматически**: если официальный
  релиз whisper.cpp ещё не публикует Vulkan-сборку для Windows, автоматически
  используется доступная сборка сообщества — без флагов и без предупреждений
  о происхождении. По-прежнему можно подложить свою сборку (whisper-cli.exe)
  в `models\whisper-cpp\`.
- Скачивание рантайма стало надёжнее: две попытки поверх curl-ретраев
  (transient-сбои сети больше не срывают установку).
- Установщик и диагностика сообщают итог коротко и по делу:
  «Декодирование аудио/видео будет использовать: CUDA / Vulkan / CPU».

## Требования к обновлению

- Обычное обновление: распаковать архив релиза и запустить `setup.cmd`
  (Windows). Переиндексация не требуется.
