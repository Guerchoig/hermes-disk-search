# hermes-disk-search v0.5.3

## Исправления и улучшения установки (whisper.cpp / Vulkan)

- **`vulkan-setup` устанавливает бэкенд полностью автоматически**: если официальный
  релиз whisper.cpp ещё не публикует Vulkan-сборку для Windows, автоматически
  используется доступная сборка сообщества — без флагов и без предупреждений
  о происхождении. По-прежнему можно подложить свою сборку (whisper-cli.exe)
  в `models\whisper-cpp\`.
- Скачивание рантайма стало надёжнее: две попытки поверх curl-ретраев
  (transient-сбои сети больше не срывают установку).
- Установщик и диагностика сообщают итог коротко и по делу:
  «Декодирование аудио/видео будет использовать: CUDA / Vulkan / CPU».

## Исправления по итогам тестирования на второй машине

- **Корни индексации из UI теперь сохраняются**: поле «Корни» раньше было
  декоративным (не сохранялось, watcher/индексатор молча использовали старые
  пути из config.yaml). Новый эндпоинт `/api/roots/save` + кнопка
  «💾 Сохранить корни» записывают `index.roots` в config.yaml с сохранением
  комментариев и соседних ключей; поле предзаполняется из настроек.
- **Понятные подсказки по эмбеддингам**: ошибка «Эмбеддинги недоступны» теперь
  различает ситуации «модель скачана, но не загружена в LM Studio» (как загрузить:
  веб-интерфейс → «Модель эмбеддингов» → «Загрузить в LM Studio») и «LM Studio
  не запущен» (Developer → Start Server).
- Инсталляторы проверяют, что модель эмбеддингов **реально загружена** в сервер
  LM Studio (а не просто скачана), с точными указаниями в каждом случае.

## Требования к обновлению

- Обычное обновление: распаковать архив релиза и запустить `setup.cmd`
  (Windows). Переиндексация не требуется; если корни индексации были изменены
  только в UI и не сохранялись — задайте их заново и нажмите «Сохранить корни».
