# Поиск по компьютеру — только через MCP-сервер `disk-search`

Любой запрос «найди на этом компе/диске…», «где у меня…», «покажи файлы/фильмы/
картинки/музыку/проекты…» выполняется инструментами MCP-сервера **disk-search**:

- `disk-search__search_local_files` — поиск по имени, теме и содержимому
  (`query`, `kinds`, `limit` ≤ 30);
- `disk-search__ask_my_files` — обзорный ответ по СОДЕРЖИМОМУ с цитатами [N]
  (его генерирует локальная LLM, это 1–3 минуты; `limit` задаёт глубину выборки:
  15–30 для вопросов «какие есть…»);
- `disk-search__index_status` — если результат пуст или индекс мог устареть.

Правила работы:

1. **Одна выдача — это фрагменты, а не список файлов.** На вопросы «найди все…»,
   «есть ли ещё…», «какие есть…» делай НЕСКОЛЬКО запросов разными формулировками и
   синонимами (русский / английский / транслит), с разными `kinds` и `limit`, и
   только потом объединяй найденное в ответ. Неполную выборку нельзя выдавать за
   полную: если очевидно, что файлов больше — продолжай поиск другими запросами.
2. Не искать файлы через терминал (`dir /s`, `find`, `grep`) и встроенный поиск по
   файлам: индекс покрывает все диски и отвечает за секунды, обход дерева идёт минуты
   и падает на недоступных каталогах. Терминал — только для действий с найденным.
3. В ответе всегда указывай путь файла (и страницу/таймкод, если они есть).
4. Если по одной формулировке пусто — это не значит, что файла нет: пробуй другие
   варианты написания и сообщай, какие запросы уже сделаны.
