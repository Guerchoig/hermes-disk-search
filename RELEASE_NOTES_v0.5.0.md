# hermes-disk-search v0.5.0

## Новое

- **GPU-ускорение транскрипции для AMD/Intel — Vulkan-бэкенд (whisper.cpp)**.
  Авто-детекция устройства (`index.whisper_device: auto` по умолчанию):
  **CUDA → Vulkan (whisper.cpp) → CPU (int8)**; на macOS — **Metal через mlx-whisper**
  (инсталлятор ставит его на Apple Silicon автоматически), иначе CPU.
  Установка Vulkan-бэкенда: автоматически из setup.ps1 (если CUDA не найдена и есть GPU)
  или `.venv\Scripts\python.exe -m hds.cli vulkan-setup [--unofficial]`.
- **Единый установщик Windows**: setup.ps1 теперь делает всё — Python-детекция (с диагностикой
  заглушки Microsoft Store), ffmpeg/Tesseract через winget, venv, зависимости, модель
  эмбеддингов, диагностика, ярлык, автозапуск, интеграция с Hermes.
  `installers\install_windows.ps1` оставлен как обёртка.
- **Автоскачивание модели эмбеддингов bge-m3** (~1,2 ГБ) инсталляторами Windows/macOS
  с проверкой наличия в папке моделей LM Studio; кнопка «Скачать/Загрузить модель»
  в веб-интерфейсе (карточка «Модель эмбеддингов»).
- **Карточка «Компоненты» в веб-интерфейсе**: живая диагностика всех компонентов
  (БД, LM Studio, чат-модель, эмбеддинги, Tesseract, ffmpeg, faster-whisper, mpxj)
  с краткими инструкциями по установке недостающего.
- **Устойчивость UI**: веб-интерфейс запускается даже с отсутствующим или испорченным
  config.yaml (авто-создание дефолтного, понятные сообщения об ошибках, правка настроек
  из UI). Команда `ui`/`check` тоже создаёт конфиг автоматически.
- **Параметр `index.whisper_language`** (`""` = авто-детекция, `"ru"` — фиксировать русский):
  авто-детект языка на маленьких моделях (tiny/base) на коротких русских фразах
  иногда ошибается — фиксирование надёжнее. Проверено на Vulkan-бэкенде.
- **Логи UI-сервера**: `%LOCALAPPDATA%\hermes-disk-search\ui.log` / `ui.err.log`;
  при незапустившемся сервере последние строки ошибки показываются прямо в окне.
- Ярлык «Hermes Disk Search» создаётся setup.ps1 (рабочий стол учитывает OneDrive).
- Кросс-платформенные исправления: остановка процессов и перенос БД на macOS
  (psutil вместо taskkill), запуск watcher'а из UI на macOS.

## Исправления

- Ложная критическая ошибка «database is locked» в `check` при параллельной записи
  watcher'а — теперь некритичное предупреждение.
- Захардкоженные пути `C:\Users\Sasha\...` в install_hermes.ps1 — заменены
  на вычисляемые (установка на других машинах/путях работала неправильно).
- Чат-модель в `check` сравнивается толерантно к суффиксу квантизации
  (`qwen3.5-9b@q6_k` vs `qwen3.5-9b`) с подсказкой точного имени.
- Существующая `.venv` из архива с чужими путями пересоздаётся автоматически.

## Требования к обновлению

- Обновление через установщик: запустите `setup.ps1` повторно — установка идемпотентна;
  конфиг не перезаписывается (пути на отсутствующих дисках предлагается заменить).
- После установки перезапустите watcher/индексацию кнопками в веб-интерфейсе.
- Полная переиндексация не требуется.
