# Релиз v0.5.8

## Исправления

- **UI больше не открывается дважды по ярлыку.** При холодном старте страницу
  открывали и UI-сервер (`webbrowser.open`), и лаунчер `run_ui.ps1` — получались
  две вкладки. Теперь сервер запускается с `--no-browser`, страницу открывает
  только лаунчер (после подтверждённой готовности сервера).
- **MCP `start_indexing` запускал индексацию дважды** — строка
  `threading.Thread(...).start()` была продублирована: два параллельных прогона,
  удвоенная нагрузка и неверный статус «не запущена» после завершения первого.
- **Надёжный перезапуск UI-сервера при несовпадении версий** (`run_ui.ps1`):
  после остановки старого процесса лаунчер ждёт фактического освобождения порта
  (до 10 с, вместо `Start-Sleep 1`), ищет процессы по командной строке без
  фильтра по имени (pythonw/python, включая venv-«шим»), после старта сверяет
  версию на порту и при необходимости перезапускает. Раньше на медленных машинах
  новый сервер мог увидеть занятый порт и молча выйти («UI-сервер не запустился»).
- **Разбор версии в `run_ui.ps1` стал устойчивым**: при неудаче Select-String
  ложно срабатывал перезапуск при каждом запуске.
- **`assets/ui.html` приведён к валидному виду**: карточка «Расположение базы
  индексации» и подпись про `index.roots` находились после `</html>`
  (последствие битого слияния) и рендерились вне контейнера; лишние `</div>`
  убраны. Деревья папок теперь перезагружаются при повторном раскрытии
  (флаг «загружено» ставится только при успехе).
- **CSRF-защита локального API**: POST-эндпоинты принимают только запросы
  собственной страницы (`Origin: http://127.0.0.1:<порт>` +
  `Content-Type: application/json`); cross-origin запросы из браузера
  отклоняются (403/415). Раньше любая открытая страница могла, например,
  остановить watcher или править `config.yaml`.
- **Автозапуск watcher — единый источник истины в UI**: учитываются и задача
  Task Scheduler (`HermesDiskSearchWatch`), и ярлык в Startup; выключение
  галочкой убирает оба механизма. Раньше при задаче в планировщике UI показывал
  «автозапуск: выкл» и не выключал её.
- **Логи UI-сервера**: `ConnectionResetError` при закрытии вкладки браузера
  больше не пишут трейсбеки в `ui.err.log`.

## Гигиена

- Из репозитория удалён устаревший ярлык «Индексация дисков.lnk».
- Убраны дублирующиеся импорты (`hds/dbops.py`, `hds/extract_av.py`), дубль
  метода `_find` в тестах, устаревшая ссылка на `install_windows.ps1` в
  `run_index.ps1`.
- `releasing.md`: новый шаг — файлы, вызываемые установщиками, должны быть
  закоммичены (релиз собирается `git archive HEAD` из закоммиченного состояния).
- Интеграция с Cline Desktop добавлена в репозиторий (`install_cline.ps1`,
  `installers/cline_mcp_merge.py`, `installers/install_cline_macos.sh`,
  `hermes-skill/disk-search.md`) — `setup.ps1` ссылается на эти файлы.

## Тесты

- 139 регрессионных тестов зелёные (+11: лаунчер, однопоточность
  `start_indexing`, структура `ui.html`, CSRF-гард).

## Требования к обновлению

- Специальных действий не требуется: миграций БД нет, `config.yaml` совместим.
- После обновления запустите UI ярлыком — устаревший сервер v0.5.7 будет
  перезапущен автоматически.
