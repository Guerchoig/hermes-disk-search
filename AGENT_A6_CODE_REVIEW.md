## 1. Вердикт

**Готово с замечаниями.** A6.1–A6.8 реализованы в том объёме, что обещан отчётами: диагностика
даёт 12 пунктов без значений секретов и без дублей в `hds check`, `--all` держит изоляцию по
`sync.lock`, горячий конфиг честно переживает битый YAML, restore/rebuild/relink и `project rm`
дают те коды и следы, которые описаны, AG-23/25/26/32 закрыты тестами, `disk_search` по умолчанию
выключен и это видно на реальном плане (`servers: []`), числа K1 воспроизводятся из артефактов.
Выпуск 0.27.0 — Windows-only: mac-джоб/ассетов нет, mandatory-ассеты на месте, sha256 зеркала
рантайма совпадает с манифестом, версия `hds/__init__.py` равна тегу.
Блокеров нет. Главные замечания — **«Вернуть» заменяет текущий оригинал без копии текущей версии**
(и без отката при сбое пересборки образа), подтверждённый **AG-34** (`hds stop` не «освежает»
пустой `index.stop`) и **ложная документация про остановку демона «после текущего файла»** —
сигнал проверяется только между проходами. Плюс пачка minor/nit по гонкам (ротация журнала
решений, `--once` без lock, TOCTOU в `project rm`) и по точности документов/CI.
