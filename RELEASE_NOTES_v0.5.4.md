# hermes-disk-search v0.5.4

## Исправления UI (блокировали работу с корнями индексации)

- **«Ошибка» при «Сохранить корни» устранена**: на Windows `os.replace` для
  config.yaml падал с PermissionError, если файл в этот момент был открыт
  на чтение соседним потоком UI-сервера (status-поллинг каждые 2 секунды).
  Все записи config.yaml (корни, исключения, опции, YAML-редактор, перенос
  базы) теперь идут через `config.replace_file` с ретраями (до 20 попыток).
- **Теперь виден настоящий текст ошибки**: если сохранение не удалось,
  UI показывает конкретную причину, а не безликое «Ошибка»; при недоступности
  сервера — подсказка «обновите страницу (Ctrl+F5)».
- **ui.html отдаётся с Cache-Control: no-store** — после обновления файлов
  проекта браузер всегда забирает свежую страницу (раньше кэшированная страница
  могла обращаться к эндпоинтам, отсутствующим в работающем старом сервере).

## Требования к обновлению

- Установите поверх: распакуйте архив релиза, запустите `setup.cmd`.
- После обновления: **остановите старый UI-сервер** (если был запущен —
  кнопка/процесс pythonw) и запустите заново через ярлык «Hermes Disk Search»,
  в браузере сделайте Ctrl+F5. Переиндексация не требуется.
