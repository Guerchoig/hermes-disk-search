# hermes-disk-search v0.2.0

Локальный поиск по вашим дискам со свободным запросом на естественном языке.
Работает поверх Hermes Agent Desktop + LM Studio на CUDA-видеокарте.

## Новое

- **Веб-интерфейс** (`python -m hds.cli ui`, ярлык «Hermes Disk Search»): запуск/пауза/
  продолжение/остановка индексации, живой статус (текущий файл, фаза, %), редактор
  config.yaml, управление watcher'ом и его автозапуском, атомарный перенос базы
  (`db_path`) с возвратом состояния watcher'а и индексации;
- **🌳 Деревья папок индексации** с раскраской: зелёный — обработано, жёлтый — частично,
  обычный — не начата (сворачивание папок нативными `<details>`);
- **Наблюдатель файловой системы** (watch): мгновенная индексация изменений с автозапуском
  при входе в систему (Планировщик задач / автозагрузка, фолбэк автоматический);
  наблюдение включается до стартовой сверки — изменения во время долгого обхода не теряются;
- **Безопасная остановка** индексации: Ctrl+C, `index.stop`, MCP `stop_indexing`, CLI `stop`;
- **Перенос индексной БД** (`db-move`/UI): консистентная копия, проверка, атомарное
  переключение конфига, старая БД остаётся резервной копией, watcher/индексация возвращаются;
- **Корзина исключена** из индексации (Windows `$RECYCLE.BIN`, macOS `.Trash`/`.Trashes`),
  в т.ч. в событиях наблюдателя;
- **Whisper**: локальная модель (`models\whisper-small\`, скачивание через curl, офлайн),
  батчевая транскрипция (ускорение ×3–5), fallback на CPU при зависании CUDA,
  cuBLAS/cuDNN 12 через pip (кросс-процессные DLL-пути);
- **Прогресс в живой строке**: текущий файл, фаза, % транскрипции и эмбеддингов;
- **Лимит чанков на файл** (`index.max_chunks`) — гигантские CSV/логи не захватывают индекс;
- MCP-инструменты: `stop_indexing`, `reindex_path`, расширенный `index_status`.

## Исправления

- `indexed_at` записывался в БД, но не обновлялся → жёлтые статусы папок; теперь
  записывается при завершении + бэкфилл старых записей;
- не начатые папки отображались как «частично обработанные»;
- `chunk_count` не записывался → переименованные файлы переиндексировались заново;
- `os.kill(pid, 0)` на Windows убивал процесс вместо проверки — заменён на ctypes;
- предупреждения HuggingFace подавлены и заменены русскими сообщениями;
- mcp 2.x (переименование FastMCP) — поддержаны обе версии SDK.

## Требования к обновлению

- После обновления: перезапустить Hermes Desktop и watcher (или ПК);
- Скачайте embedding-модель `text-embedding-bge-m3` в LM Studio (если ещё не скачана);
- Изменения схемы БД применяются автоматически; полный пере-поиск не требуется.
