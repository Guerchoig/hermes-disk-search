# Поиск по компьютеру через disk-search

## Когда применять

Для ЛЮБЫХ запросов вида «найди на этом компе/диске…», «где у меня…», «покажи файлы…» —
вне зависимости от типа: документы, проекты (1С, MS Project), фильмы/видео, музыка,
картинки/фото, PDF. Это относится и к «найди фильмы», «найди изображения цветов» —
индекс хранит имена файлов, метаданные, OCR картинок и транскрипции видео.

## Как

1. Поиск по имени/теме: `mcp__disk_search__search_local_files` с аргументами:
   - `query` — запрос (можно на естественном языке);
   - `kinds` — фильтр типа: `"media"` (фильмы/видео/музыка), `"image"` (картинки),
     `"mpp"` (MS Project), `"docx,xlsx,pptx"` (офисные), `"pdf"`, `"text"`;
   - `limit` — до 30.
2. Развёрнутый ответ по СОДЕРЖИМОМУ («о чём этот документ», «в каких файлах
   упоминается X»): `mcp__disk_search__ask_my_files`.
3. Если результат пуст, а файлы точно есть: `mcp__disk_search__index_status` —
   возможно, индексация ещё идёт (тогда честно сказать пользователю и повторить позже).

## Чего НЕ делать

- Не использовать встроенный `search_files` (ripgrep) и команды `terminal`
  (find/ls/grep) для поиска файлов: индекс покрывает сотни тысяч файлов на всех
  дисках и отвечает за секунды, а обход дерева — минуты и падает на недоступных
  каталогах.
- `terminal` — только для действий с найденным (открыть, скопировать, переместить).

## Источник истины

Индекс БД: `D:\hermes-disk-search-db\index.db` (проект hermes-disk-search).
Если индекс пуст или сильно устарел — сообщить пользователю, запускать
`mcp__disk_search__start_indexing` только по его согласию.
