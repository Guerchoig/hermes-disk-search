# Поиск по компьютеру через disk-search

## Когда применять

Для ЛЮБЫХ запросов вида «найди на этом компе/диске…», «где у меня…», «покажи файлы…» —
вне зависимости от типа: документы, проекты (1С, MS Project), фильмы/видео, музыка,
картинки/фото, PDF. Это относится и к «найди фильмы», «найди изображения цветов» —
индекс хранит имена файлов, метаданные, OCR картинок и транскрипции видео.

## Как

1. Поиск по имени/теме — инструмент `search_local_files` MCP-сервера `disk-search`
   (в Cline вызывается через use_mcp_tool: server_name = "disk-search",
   tool_name = "search_local_files") с аргументами:
   - `query` — запрос (можно на естественном языке);
   - `kinds` — фильтр типа: `"media"` (фильмы/видео/музыка), `"image"` (картинки),
     `"mpp"` (MS Project), `"docx,xlsx,pptx"` (офисные), `"pdf"`, `"text"`;
   - `limit` — до 30.
2. Развёрнутый ответ по СОДЕРЖИМОМУ («о чём этот документ», «в каких файлах
   упоминается X») — инструмент `ask_my_files` того же сервера.
3. Если результат пуст, а файлы точно есть: `index_status` — возможно, индексация
   ещё идёт (тогда честно сказать пользователю и повторить позже).

## Стратегия для фильмов, музыки и актёров

- Видео/музыка индексируются по ИМЕНИ файла и транскрипции звучащей речи.
  Имя актёра почти никогда не встречается в имени файла — запрос «фильмы с
  Макконахи» по имени актёра может не находить файлы с его фильмами.
- Ищи по НАЗВАНИЮ фильма, несколькими запросами: русское название
  («Золото дураков»), английское («Fool's Gold»), транслит («Zoloto durakov»).
  Семантическая модель связывает русское название с транслитом в имени файла.
- Перебери 3-5 известных фильмов актёра отдельными запросами search_local_files
  с kinds="media" и обобщи результат.
- Если по одному названию пусто — это не значит, что фильма нет; пробуй другие
  варианты написания и сообщи пользователю, какие запросы были сделаны.

## Чего НЕ делать

- Не использовать встроенный поиск по файлам (search_files/ripgrep) и команды
  терминала (find/ls/grep, dir /s) для поиска файлов: индекс покрывает сотни тысяч
  файлов на всех дисках и отвечает за секунды, а обход дерева — минуты и падает
  на недоступных каталогах.
- Терминал — только для действий с найденным (открыть, скопировать, переместить).

## Источник истины

Индекс БД: путь `db_path` из `config.yaml` проекта hermes-disk-search
(по умолчанию `%USERPROFILE%\hermes-disk-search-db\index.db` на Windows или
`~/hermes-disk-search-db/index.db` на macOS).
Если индекс пуст или сильно устарел — сообщить пользователю, запускать
`start_indexing` только по его согласию.
