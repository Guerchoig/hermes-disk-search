## Что исправлено (ревью A6)

1. **«Вернуть» (`hds agent result restore`) больше не теряет файл.** Перед заменой
   оригинала текущая версия копируется в `.hds-agent\backup\<штамп>`; занятый файл или
   сбой замены откатывают эту копию; сбой пересборки образа возвращает оригинал из
   копии, прежний статус реестра и запись `decision_failed` в журнале решений; в отчёте
   печатается штамп прежней версии.
2. **Повторный `hds stop` действительно останавливает демон (AG-34).** Файл
   `index.stop` остаётся пустым, но время изменения ставится явно, поэтому сигнал
   срабатывает и для демона, запущенного после предыдущей остановки.
3. **Ротация `decisions.jsonl` под lock-файлом** (`decisions.lock`, ожидание 1,5 с,
   снятие залипшего через 30 с); при неудаче запись идёт без ротации — строки не
   теряются. `hds agent history clear` журнал по-прежнему не трогает.
4. **`hds agent sync --all --once` занимает `sync.lock`** (AG6-06): ручной проход не
   идёт параллельно с автозапуском, занятый lock — «уже запущен» и код 0.
5. **`agent project rm` перепроверяет живой демон** непосредственно перед удалением,
   а запрет «папка проекта внутри `agent.root`» переехал в общий `projects::validate`
   (CLI и вкладка «Агент» ведут себя одинаково).
6. **`disk-search` из `mcp.servers` больше не подставляется**, когда встроенный поиск
   выключен; `tavily`/`1c-buddy` из шаблона поставки работают как раньше.
7. **Диагностика и обслуживание:** `agent-index` смотрит **все** пути проекта (а не
   первую строку); `--all` при недоступных папках **всех** проектов выходит с кодом 0 —
   задача автозапуска не уходит в перезапуски по кругу; `reap_idle` вызывается и из
   `/api/agent/events`; задача Планировщика регистрируется с `-Hidden`.
8. **Windows-CI** собирает Node-воркер (`setup-node` + `npm ci` + `npm run build`) в
   `rust.yml`/`release.yml`, поэтому тесты плана больше не пропускаются.
9. **Замер RAG (`--score-only`)** пишет времена прогонов в `k1-times.json` и сводку в
   `k1-summary-score.json`, не затирая исходный `k1-summary.json`.

## Что изменено по решению владельца (вариант B)

10. **Остановка демона зеркала — между файлами (AG6-02).** `hds stop` прерывает проход
    перед следующим файлом (текущий дорабатывается целиком, `wait_stable` не
    прерывается): демон завершается в пределах обработки одного файла, в `sync.log`
    остаются `pass …` и `stop reason=index.stop`, `sync.lock` снимается. После сигнала
    проход не удаляет «исчезнувшие» оригиналы — это делает следующий проход.
11. **`hds agent sync --all` перечитывает `projects.json` (AG6-15(а)).** Раз в 5 с:
    новый проект (`hds agent project add`) подхватывается без перезапуска демона, смена
    `path` перезапускает поток уже на новой папке, исчезнувший из файла проект
    останавливается — своим флагом, остальные продолжают работу. Занятый `sync.lock` и
    отказ запуска — кулдаун 60 с; `agent.enabled: false` снимает проект до перезапуска
    демона. Остановка супервизором пишется как `stop reason=restart` (новое **значение**
    причины; структура строки `stop reason=<слово> passes=N changes=M` прежняя) и общий
    `index.stop` не создаёт.
12. **`hds agent init` останавливает демон зеркала (AG6-16(б)).** После остановки
    индексатора `init` выставляет сигнал и ждёт снятия/устаревания `sync.lock` всех
    проектов; в списке «Будет очищено» появляется строка «Демон зеркала: запущен —
    будет остановлен». Если демон не остановился за 60 с — код 1 с подсказкой `hds stop`,
    база не удаляется. `index.stop` снимается только после этого.

## Требования к обновлению

* **Переиндексация не нужна:** схема БД поиска и состав полей не менялись.
* **Формат журналов** `sync.log`/`decisions.jsonl` и коды возврата CLI не менялись; в
  `sync.log` добавлено одно новое значение причины остановки — `restart` (см. п. 11).
* **Демон зеркала:** обновление подменяет каталог версии за `app\current`, запущенный
  демон продолжает работать на прежних файлах — остановите его (`hds stop`) перед
  обновлением; после входа в систему задача `HermesDiskSearchAgentSync` поднимет его
  заново (вручную — `installers\install_agent_sync_task.ps1 -Start`).
* Проект без папки больше не блокирует остальные; после `hds agent init` зеркало
  поднимается обычным порядком.
