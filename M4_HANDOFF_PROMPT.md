## Ключевые решения (заказчик; полнее — `PLAN_SERVER_MULTIUSER.md`)
- **SLA ≤5 мин** для 5 одновременных RAG; при нехватке VRAM — **явная ошибка с числами**, а не
  молчаливая деградация (решение 29.09.2026).
- Периметр — reverse-proxy с TLS; наружу только `/mcp` и `/ui`; UI — только админ (M3).
- Идентификация — локальные токены; индексация — только админ; проект — единица выдачи (M1).
- Внешний API допустим (анонимизация — позже): это **задел M5** (`chat.provider: remote`, Э6) —
  в M4 только контракт ключей (§3.5 плана), реализация — следующим этапом.
- **Десктоп-профиль не ломаем:** очередь/квоты выключены, лимиты/аудит — как в M3 (выключены).

## Контракты (кратко; детали — план §3)
- **Слоты:** `llm_server.parallel` (server — 5), `ctx_per_slot`; проверка
  `estimate_need_mib`/`check_fit` (бюджет уже есть в `crates/hds-llama/src/budget.rs`).
- **Очередь:** `queue: {enabled,max_depth,wait_timeout_sec,policy}`; ключ — пользователь,
  round-robin между пользователями / FIFO внутри; переполнение → `429`, таймаут → `503`,
  оба с `Retry-After`; метрики в диагностике.
- **Квоты:** ключ `user:<login>` (иначе `ip:<addr>`), `rate_limit.max_inflight_per_user`,
  `requests_per_min_per_user`; пер-токенные лимиты — опция.
- **БД:** `journal_mode=WAL` + `busy_timeout` (5 с) + read-only читатели, один писатель.
- Всё — по конфигу, с серверными дефолтами и сохранением десктоп-поведения.

## Грабли окружения (кратко; полнее — tools/parity/HANDOFF_PROMPT.md)
- `git` — **всегда** `--no-pager`. PowerShell портит первый токен команды; кириллица в
  `Select-String` **не ищется** — читать файл инструментом; `**` в путях PowerShell 5.1 не
  разворачивается (используйте `Get-ChildItem -Recurse` или инструмент поиска по репозиторию).
- Скрипты `.ps1` без BOM PowerShell 5.1 читает как ANSI — **кириллица внутри строк ломает
  разбор**; для временных проб держите текст ASCII (или сохраняйте файл с BOM).
- `config.yaml` — **в `.gitignore`**; правки боевого конфига/индекса — только по решению.
  Для изоляции проб: `HDS_ROOT` + `HDS_CONFIG` (персистентны в сессии PowerShell).
- Запущенные `llm_host.exe`/`hds mcp-http`/`hds watch` держат `target\release\*.exe` → сборка
  падает «отказано в доступе»; на dev-машине их можно останавливать (`cline-rules/dev-machine.md`),
  кроме чужих процессов. Полный SCM-цикл служб — только из-под администратора.
- Замеры GPU/нагрузки: снимать резидент и **возвращать** его после (`llm_host run` или задача
  Планировщика, `installers/install_llm_host_task.ps1`).
- Проверка HTTP «как есть» (коды/заголовки) — сырым сокетом (`System.Net.Sockets.TcpClient`);
  `Invoke-WebRequest` скрывает детали. Артефакты проб — в `tools/parity/out/` (гитигнорится).
