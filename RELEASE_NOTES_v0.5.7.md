# Релиз v0.5.7

## Исправления

- **UI: секция «Последние обработанные» снова обновляется.** При индексации,
  запущенной watcher'ом или из CLI (отдельный процесс), список обработанных
  файлов не доходил до веб-интерфейса: heartbeat-файл не содержал событий.
  Теперь события включаются в `index.heartbeat.json` и видны в UI в реальном
  времени, а после завершения прогона остаются в интерфейсе (кешируются
  UI-сервером). Заодно убрано дублирование кода чтения heartbeat в `/api/status`.
- **Диагностика (`check`, карточка «Проверка компонентов»):** таймаут опроса
  LM Studio увеличен с 3 до 10 секунд — на медленных машинах проверка эмбеддингов
  ложно падала; сообщение о недоступных эмбеддингах стало понятнее и содержит
  подсказку («Скачайте модель» → «Загрузить в LM Studio»).
- **Инсталлятор Windows (`ensure_embedding_model.ps1`) больше не создаёт
  дубликаты экземпляра** `text-embedding-bge-m3` в LM Studio: перед загрузкой
  проверяется `lms ps`, найденные копии выгружаются (дубликаты расходовали VRAM).
- **UI:** карточка Watcher перенесена выше, рядом с индексацией.
- Тесты: стабилизирован `test_vulkan_not_supported_falls_back` (явный
  `cpp_available=False`) — больше не зависит от наличия whisper.cpp на машине.

## Инструменты диагностики (новое)

- `tools/diag_index_speed.py` — пошаговая диагностика медленной индексации на
  машине без CUDA (AMD/Vulkan): сервер LM Studio, конкуренция за GPU,
  скорость эмбеддингов продакшн-путём, опционально RTF whisper.cpp.
- `tools/bench_paths.py` — бенчмарк фаз индексации (`embed` / `transcribe`)
  ровно по продакшн-коду (chunker + Embedder, faster-whisper / whisper.cpp).
- `tools/DIAG_SLOW_MACHINE.md` — методика диагностики с эталонными цифрами
  (RTX 3060: эмбеддинги ~33 мс/чанк; транскрипция 2 мин аудио: RTF 0.010–0.135).

## Требования к обновлению

- Специальных действий не требуется: миграций БД нет, config.yaml совместим.
- После обновления перезапустите UI-сервер и watcher (новые версии файлов).
