# RELEASE_NOTES v0.16.1 — устойчивость на живых машинах: перезапуск, диаризация, OCR

> Патч-релиз: исправления по живым инцидентам на реальных машинах (в т.ч. на
> ноутбуке с AMD iGPU и Vulkan-движком). Rust-проверки зелёные: `cargo fmt
> --check`, `clippy -D warnings`, `cargo test --workspace`.

## Исправления

* **Перезапуск llm-host переживает краш резидента.** Если резидент упал нативно
  (pid-файл остался, HTTP не отвечает), кнопка «Перезапустить llm-host» раньше
  отменялась через 60 с («резидент не завершился»). Теперь: pid-файл от мёртвого
  процесса снимается, живой зависший процесс завершается принудительно
  (taskkill, как `llm_host stop --force`) — и перезапуск продолжается. Отмена
  остаётся только если принудительное завершение не удалось.
* **Диаризация на Vulkan/Metal-движках.** Имя устройства для диаризации
  хардкодилось `CUDA{индекс}` — на движках с Vulkan/Metal такого бэкенда нет, и
  транскрибация падала `native realtime diarization failed: failed to
  initialize backend: CUDA0` (живой инцидент: ноутбук AMD, whisper в очереди).
  Теперь имя берётся из живого списка устройств движка (`Vulkan0`/`CUDA0`/
  `Metal0`), для CPU-пути — `whisper_no_gpu`.
* **UI больше не мигает «идёт ↔ пауза» во время индексации.** Роли
  `embedding`/`rerank` обслуживают запросы самого индексатора, и
  `pause_index_on_query` ставил паузу индексации на каждый запрос эмбеддингов —
  «индексатор ставил паузу сам себе» (файл `index.pause` появлялся/исчезал на
  каждый батч). Для index-serving ролей действие убрано; пауза остаётся для
  пользовательских запросов (chat) и транскрибации.
* **OCR (Tesseract) конфигурируется установщиком на обеих платформах.** Шаг
  `configure_ocr.py` был задуман, но из установщиков выпал (setup.ps1 не вызывал
  его вовсе; install_macos.command — тоже). Теперь setup.ps1 и
  install_macos.command запускают его на каждой установке/обновлении: поиск
  tesseract (PATH + стандартные каталоги / brew-пути), языковые пакеты rus+eng
  в пользовательском tessdata (без админ-прав), прописывание
  `index.ocr_tesseract_cmd` в config.yaml. Сам `configure_ocr.py` работает и в
  релизной поставке — без Python-пакета `hds` и PyYAML (фолбэк: config.yaml из
  config.example.yaml + текстовая правка). Tesseract можно устанавливать в
  любой момент: следующая установка/обновление подхватит его сама.

## Требования к обновлению

* Штатное обновление поверх 0.16.x: распаковать архив, `setup.cmd`/`setup.ps1`
  (или `installers\update.ps1`); переиндексация не требуется.
* После обновления перезапустите llm-host (кнопка в UI) и, если используете
  автотранскрибацию — демон подхватит файлы из очереди сам.
* Если whisper-транскрибация на Vulkan/Metal вызывает проблемы конкретного
  железа — принудительный CPU: `auto_transcribe.whisper_gpu: -2`.
