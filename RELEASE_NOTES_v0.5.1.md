# hermes-disk-search v0.5.1

## Новое

- **Установка из скачанного архива без блокировок ОС**:
  - Windows: двойной клик по **`setup.cmd`** — обёртка снимает пометку
    «скачано из интернета» (MotW / Zone.Identifier) со всех файлов проекта
    (Unblock-File) и запускает установщик с `-ExecutionPolicy Bypass`.
    Обёртка ASCII-only: cmd.exe парсит batch-файлы в OEM-кодировке, и
    кириллица в них ломает разбор на русской Windows. Сам setup.ps1
    дополнительно снимает MotW при каждом запуске;
  - скачанные Vulkan-рантаймы whisper.cpp разблокируются автоматически
    (снятие Zone.Identifier после распаковки);
  - macOS: `install_macos.command` снимает карантин Gatekeeper
    (`xattr -dr com.apple.quarantine`) с проекта и установленного
    приложения «HDS Индексация» — скачанный архив больше не «повреждён»;
  - mac-приложение в релизе подписано **ad-hoc** (codesign, бесплатно) —
    вместе со снятием карантина приложение запускается без Gatekeeper-блокировок.

## Документация

- README: раздел «Блокировки «скачано из интернета» и цифровая подпись» —
  как работают MotW/Gatekeeper в проекте и что делать для полной подписи
  (Windows: Authenticode + signtool, платно; macOS: Apple Developer Program
  + нотаризация, $99/год). Без сертификатов связка Unblock-File + Bypass +
  xattr решает запуск полностью.

## Требования к обновлению

- Обычное обновление: распаковать архив релиза и запустить `setup.cmd`
  (или `setup.ps1` через Bypass) — установка идемпотентна, переиндексация не нужна.
